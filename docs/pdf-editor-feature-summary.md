# 阅读：PDF 编辑器已有功能汇总

更新时间：2026-08-09（北京时间）

## 产品定位

“阅读”是一个 Android PDF 阅读与编辑应用，基于 Jetpack Compose、PDFBox Android 和 Android Storage Access Framework。应用不上传用户 PDF；文件由用户通过系统文件选择器明确选择，网络仅用于用户主动发起的在线更新检查。

## 入口与阅读

- 首页提供“阅读 PDF”“编辑 PDF”“电子书”三个主要入口。
- 支持连续纵向阅读、页面跳转、阅读历史和断点恢复。
- 支持缩略图、PDF 目录、应用内书签、全文搜索和当前页文本复制。
- 支持页内链接、网页链接和附件入口。
- 支持全屏阅读、适合宽度、适合高度、平移、捏合缩放和高清区域渲染。
- 支持 EPUB 与 TXT 电子书阅读。
- 支持浅色、深色、跟随系统主题以及强调色设置。

## PDF 对象编辑

- 解析页面内容流中的文本、路径、图片和 Form XObject。
- 编辑对象位置、尺寸、旋转、颜色、透明度、线宽、线帽、线连接方式和混合模式。
- 编辑文本内容、字号、字体、字距、行距和多行文本。
- 支持导入设备字体、应用内置字体和字体编码失败提示。
- 支持替换图片、图片裁剪、插入文本、插入图片、插入矩形和直线。
- 支持单选/多选、复制、粘贴、删除、锁定/解锁、撤销和重做。
- 支持页面中心、边缘和对象边缘的智能吸附。
- 支持水平/垂直对齐和等间距分布。
- 支持安全范围内的图层前移、后移、置顶和置底。
- 对复杂外部绘制状态、跨内容流、部分 Form 和复杂裁剪结构会主动拒绝危险操作。

## 页面管理

- 删除当前页或批量删除页面。
- 复制当前页或批量复制页面。
- 单页移动、批量前移/后移和移动到指定位置。
- 插入空白页。
- 从另一个 PDF 导入页面。
- 批量旋转页面。
- 裁剪/恢复页面裁剪框。
- 调整页面尺寸。
- 按页码范围或固定页数拆分 PDF。
- 导出所选页面，并在页面导出前检查表单、标签结构、可选图层、动作、名称树和链接风险。
- 新增多 PDF 顺序合并，输出前经过临时文件校验。

## 批注、遮盖与签名

- 高亮、下划线、删除线。
- 便签、FreeText、图章。
- 手写签名和批注移动。
- 批注颜色、透明度、内容和 FreeText 字号编辑。
- 批注锁定/只读状态保护。
- 永久遮盖 Redaction，包含 OCR 生成文字层的安全处理。
- PKCS#12/PFX 证书选择、可见/不可见数字签名、签名原因/地点/联系方式。
- 数字签名状态、证书有效期、证书链和后续增量修改检查。

## 文档级能力

- PDF 标题、作者、主题、关键词等元数据编辑。
- PDF 目录新增、修改、移动和删除。
- PDF 链接新增、修改、删除以及 URI/页内目标校验。
- PDF 附件新增、重命名、导出和删除。
- AcroForm 文本框、复选框和下拉框创建，已有字段填写与字段删除。
- OCR 识别并写入可搜索文字层。
- 图片重编码压缩，提供轻度、均衡和强力预设。
- 水印和页码批量添加。
- 用户密码、所有者密码、打印/复制/修改/批注/表单/辅助功能/页面组装权限设置。
- 支持 AES-128 和 AES-256 PDF 加密。
- 加密 PDF 密码输入、错误重试和权限门禁。

## 保存与恢复

- 支持另存为和覆盖保存。
- 覆盖保存前使用来源文件指纹检测外部修改。
- 保存前先写入临时文件，再重新解析校验页数、页面尺寸、旋转、批注、表单和目录。
- 覆盖失败时尝试使用备份恢复原文件。
- 未保存编辑会写入恢复文件，应用重新打开时可选择恢复或放弃。
- 已有数字签名或无法确认签名状态的文档禁止覆盖保存。

## 系统集成

- 支持通过 Android `VIEW` Intent 打开 PDF、EPUB 和 TXT。
- 支持系统文件选择器读写文档。
- 支持在线检查 GitHub Release 更新、下载 APK 和调用系统安装器。
- 支持将当前 PDF 通过 Android 系统分享。
- 支持调用 Android 系统打印服务打印当前 PDF。

## 当前边界

- 页面合并以页面内容和资源为主，多个源文档的目录、表单、附件和文档级动作不会自动拼接为一套统一结构。
- 复杂 Tagged PDF、可选内容组、脚本动作、命名目标和跨 Form 结构会优先安全拒绝，而不是静默生成结构残缺的文件。
- 尚未实现 TSA/OCSP/CRL/PAdES-LTV、PushButton/签名表单字段、XFDF 批注交换、PDF/A/UA 合规检查和文档比较。
- 全文搜索目前按页面提取文本，超大文档仍可进一步引入持久化搜索索引和命中高亮。
